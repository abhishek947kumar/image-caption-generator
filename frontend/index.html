    CNN-LSTM Multi-Modal Architecture

    Visual-to-Semantic encoding and autoregressive sequence decoding pipeline

    Step 1: Vision Encoder
    Pre-trained CNN
    MobileNetV3 / ResNet-50

    Transforms RGB image $(224 \times 224 \times 3)$ into a high-level spatial visual feature vector (1024-D / 2048-D).

    Output: Tensor [1, 1024]
    →
    Step 2: Projection
    Linear Dense Layer
    Linear + LayerNorm + ReLU

    Projects CNN visual representations into the joint multi-modal embedding space (256-D).

    Output: Tensor [1, 256]
    →
    Step 3: Language Decoder
    Recurrent LSTM
    Hidden Dim: 512

    Maintains sequential grammar state $h_t, c_t$. Conditioned on previous word tokens and visual context.

    State: [1, 512]
    →
    Step 4: Decoding
    Greedy / Beam Search
    Softmax → Vocabulary

    Calculates probability over full vocabulary. Generates caption word by word until <end> token.

    Training Guide & Flickr8k Workflow

    Step-by-step instructions to train the CNN-LSTM on the 8,000-image benchmark

    1. The Flickr8k Dataset Structure

    The Flickr8k dataset consists of 8,092 high-resolution real-world images, each paired with 5 human-annotated descriptive captions (totaling 40,460 captions). The dataset is divided into:

    • Flicker8k_Dataset/: Directory containing 8,092 JPEG images.
    • Flickr8k.token.txt: Ground truth text file formatted as <image_id>#0 <caption> through #4.
    • Flickr_8k.trainImages.txt: 6,000 image filenames for training.
    • Flickr_8k.devImages.txt: 1,000 images for validation.
    • Flickr_8k.testImages.txt: 1,000 images for testing BLEU score.

    2. Offline Feature Extraction (Speed Optimization)

    Rather than running raw images through the heavy CNN on every training epoch, we pre-extract and cache penultimate feature vectors. This reduces training epoch duration from hours down to just minutes on modern CPUs/GPUs.

    python -c "from training.train import extract_and_cache_features"

    3. Running Training with PyTorch

    Run the modular training pipeline directly via terminal:

    # Quick verification demo run (runs on sample images):
    python training/train.py --demo_train --epochs 5

    # Full Flickr8k dataset training:
    python training/train.py --data_dir data/flickr8k --epochs 10 --batch_size 32 --lr 0.001

    4. Teacher Forcing & Loss Function

    During training, the LSTM decoder is fed ground-truth tokens $w_t$ at each timestep (known as Teacher Forcing). The model outputs unnormalized logits across all $|\mathcal{V}|$ vocabulary words. We optimize using Categorical Cross-Entropy Loss while ignoring the <pad> index:

    criterion = nn.CrossEntropyLoss(ignore_index=pad_idx)
    loss = criterion(logits.view(-1, vocab_size), targets.view(-1))
